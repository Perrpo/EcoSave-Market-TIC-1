# Stack Tecnológico del Sistema — EcoSave Market

## Descripción General

EcoSave Market es una plataforma web para la gestión de productos próximos a vencer, conectando negocios, ONGs y consumidores con el objetivo de reducir el desperdicio de alimentos.
El sistema sigue una arquitectura cliente-servidor separando frontend y backend.

Arquitectura:

Frontend (React + Vite)
↓
API REST
↓
Backend (AdonisJS)
↓
Supabase (PostgreSQL + Auth)

---
